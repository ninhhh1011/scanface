# Locked API contracts (v1)

JSON snake_case fields. Dates ISO UTC, business dates YYYY-MM-DD Asia/Ho_Chi_Minh. Money integer VND strings on wire. All API responses `Cache-Control: private, no-store`. Errors `{error:{code,message,fields?}}`; never SQL/stack. Cookie `abc_session`; browser mutation Origin must match APP_URL. List `{items,total,page,page_size}`. ID is opaque UUID except seeded deterministic IDs. Auth actor `{id,email,role,employee_id,capabilities:string[]}`; role enum SUPER_ADMIN/HR_ADMIN/MANAGER/EMPLOYEE. Backend always derives scope.

Auth: POST `/api/auth/login` {email,password}; GET `/api/auth/me` returns {user}; POST logout; POST change-password {current_password,new_password}. UI sends credentials same-origin. Login no public credentials. Employee directory fields are limited; salary is separate payroll capability.

HR collections GET/POST `/api/hr/{resource}`; GET/PATCH `/api/hr/{resource}/{id}`; POST `/api/hr/{resource}/{id}/{action}` with `{reason?,...}`. Query page/page_size/search/status/department_id/employee_id/from/to/sort/order (validated). All actions refetch lists. Metadata GET `/api/hr/options` returns permitted employee identifiers, departments, positions, shifts, leave types and review cycles. Dashboard GET `/api/hr/dashboard`; reports GET `/api/hr/reports?kind=attendance|leave|overtime|headcount|contracts`; export GET `/api/hr/{resource}/export` CSV. Employee CSV POST `/api/hr/employees/import` {csv,commit:false|true}; preview validations before commit. GET `/api/hr/employees/template`.

Resources and editable payloads:
- employees: code, full_name, email, phone?, department_id, position_id, manager_id?, hire_date, status ACTIVE|ON_LEAVE|ARCHIVED; action archive.
- departments: name; positions: name.
- contracts: employee_id, title, starts_on, ends_on?, base_salary (integer string, payroll capability), status DRAFT|ACTIVE|EXPIRED|TERMINATED; terminate requires reason. Attach through documents.
- shifts: name,start_minute,end_minute,break_minutes,grace_minutes,weekdays:number[] (1=Monday … 7=Sunday).
- schedule: employee_id,shift_id,starts_on,ends_on; server rejects overlapping assignments.
- attendance: read sessions with employee_id,work_date,check_in,check_out,worked_minutes,late_minutes,early_minutes,source. POST manual requires employee_id,action CHECK_IN|CHECK_OUT,occurred_at,reason. Face attendance has separate proof path.
- corrections: employee_id,attendance_id,requested_in,requested_out?,reason; submit/approve/reject. No silent rewriting source FACE.
- timesheets: name,starts_on,ends_on; review/lock/reopen (reason).
- leave: employee_id,type_id,starts_on,ends_on,reason; draft edit, submit/approve/reject/cancel. Full workdays only. Leave balances read GET `/api/hr/leave-balances`.
- overtime: employee_id,starts_at,ends_at,reason; draft edit, submit/approve/reject/cancel.
- payroll: name,timesheet_id; calculate/review/lock/reopen; items GET detail; payroll-components: employee_id,name,amount,kind BASE|ALLOWANCE|ADJUSTMENT,reason.
- performance: employee_id,cycle_id,self_comment?,manager_comment?,score? (1–5); submit/publish. review-cycles: name,starts_on,ends_on.
- announcements: title,body,audience:string[]; publish/archive. notifications: read list, action read.
- documents: private metadata listing; upload POST multipart `/api/files` file + employee_id + title + classification GENERAL|CONFIDENTIAL|IDENTITY + optional contract_id. GET/DELETE `/api/files/{id}` rechecks ACL. Max 10MB, TXT/MD/PDF/DOCX/images; no executable/SVG.
- users: email,employee_id?,role,capabilities:string[]; lock/unlock/reset-credential (new_password, internal operator, no public credential).
- roles: role,capabilities (SUPER_ADMIN only, per-role capability settings); settings: key,value; audit: read immutable events.

Face HTTP boundary, Python-owned inference/store:
- GET Python `/healthz`; GET `/readyz` includes real model load/inference state (503 otherwise).
- Internal authorization: `Authorization: Bearer ${SERVICE_AUTH_KEY}` plus short-lived HMAC envelope `X-ABC-Scope` containing base64url JSON `{actor_id,session_id,employee_id,action,exp,nonce}` signed HMAC-SHA256 with SERVICE_AUTH_KEY, encoded `payload.signature`; reject expired or mismatched scope. Root proxies only after role/object auth. Body frame base64 JPEG limits enforced both sides.
- POST `/face/challenge` {employee_id,session_id,action:ENROLL|CHECK_IN|CHECK_OUT,actor_id,consent:boolean}; returns {challenge_id,direction:LEFT|RIGHT,expires_at,instructions}. Actual consent persisted for enrollment; scans also require consent.
- POST `/face/enroll` {challenge_id,frames:[{image:string,captured_at:number}],employee_id}; returns {status:ENROLLED,employee_id,sample_count,model_version} only after commit. 5–10 frames, consistency + quality; atomic replacement.
- POST `/face/verify` {challenge_id,frames:[...]}; returns {status: MATCHED|NO_FACE|MULTIPLE_FACES|LOW_QUALITY|NO_ENROLLED_PROFILES|UNKNOWN_PERSON|AMBIGUOUS_MATCH|LIVENESS_FAILED,proof_id?}. Proof only persisted for real match + challenge; session/action/employee bound. Employee self-service only matches expected account; no kiosk in initial scope.
- DELETE `/face/profiles/{employee_id}` deletes real templates/consent status, invalidates proofs and audits. Web exposes `/api/face/{challenge|enroll|verify|profiles/:id}` through authenticated proxy.
- POST web `/api/face/attendance` {proof_id,action}; web locks/consumes proof in same transaction as event/session update. Browser cannot choose identity or liveness. Face metadata GET in employee details, never templates.

Python SQL tables contract (root migration owner): `employees(id,status,...)`; `face_profiles(id,employee_id UNIQUE,status,model_version,dimension,sample_count,updated_at)`; `face_templates(id,profile_id,ciphertext bytea,model_version,dimension,created_at)`; `enrollment_consents(id,employee_id,actor_id,purpose,accepted_at,revoked_at)`; `face_challenges(id,employee_id,actor_id,session_id,action,direction,nonce,expires_at,consumed_at,created_at)`; `face_verifications(id,employee_id,session_id,action,challenge_id UNIQUE,model_version,expires_at,consumed_at,created_at)`; `audit_events(id,actor_id,action,resource_type,resource_id,result,reason,request_id,before Json?,after Json?,created_at)`. Ids generated in application. All timestamps timestamptz. Template plaintext never returned.

Knowledge: web `/api/knowledge` list + POST multipart file,title,version,effective_from,effective_to?,classification,allowed_roles JSON; `/api/knowledge/{id}` GET/PATCH; POST `/api/knowledge/{id}/{publish|deactivate|reindex}`; DELETE. `/api/knowledge/chunks/{id}` citation read reauthorizes. Storage key is private documents file ID.
SQL `knowledge_documents(id,title,owner_id,classification,allowed_roles text[],status,active_version_id?,created_at)`; `document_versions(id,document_id,version,effective_from,effective_to,file_id,content_hash,status,created_at)`; `document_chunks(id,version_id,ordinal,content,section,page,embedding_model,embedding_dimension,embedding vector,content_hash,created_at)`; `ingestion_jobs(id,version_id UNIQUE,status,attempts,error_code,locked_at,available_at,created_at,updated_at)`. Python polls with SKIP LOCKED, bounded retries, replaces chunks transactionally, READY only with real embeddings. Root migrates untyped vector column to allow configured dimensions, application validates dimensions/model on query. Python may not alter schema.
File download for worker: internal GET web `/api/internal/files/{id}` with service authentication (fixed scope, no arbitrary URL). Ingestion calls EMBEDDING_BASE_URL/API_KEY/MODEL/DIMENSION; supports explicitly configured OpenAI-compatible embeddings API; verify provider documentation. No runtime fake provider.

Copilot: POST `/api/assistant` {message,session_id?} returns validated {session_id,answer,citations:[{id,title,section?,page?,url}],route,as_of}; missing config 503 AI_NOT_CONFIGURED. GET `/api/assistant/sessions`; GET/DELETE `/api/assistant/sessions/{id}`. HR tools in server/ai use exported `db()` from server/db.ts and `Actor`, `employeeScope(actor)`, `can(actor,capability)`, `authorizeEmployee(actor,id)` from server/policy.ts. Audit helper `audit(tx,actor,action,resource_type,resource_id,details?)`. Provider config read via `config(name)` from server/config.ts. Guarded response after full output validation; no unvalidated streamed draft. Routes POLICY/PERSONAL_HR/TEAM_HR/ATTENDANCE/LEAVE/CONTRACT/HR_ANALYTICS/MIXED/UNSUPPORTED. Tools return only allowed fields. Morning Brief GET `/api/assistant/brief` uses same scoped evidence, deterministic statistics explicitly labeled on provider error.
